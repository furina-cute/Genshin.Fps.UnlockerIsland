# Genshin.Fps.UnlockerIsland

## ✨ 功能特性

- 帧率解锁
- 视角调整
- 画面增强
- *其他功能*

### 前置要求
- Windows 10/11 操作系统
- 已安装《原神》或《Genshin Impact》

### 游戏内操作
- `Home` 键：打开/关闭功能菜单
- 手柄 `RB + LB + X + 十字键上`：打开功能菜单
